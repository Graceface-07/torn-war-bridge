## 🚀 HOW TO USE IT (3 SIMPLE STEPS):

### STEP 1: Get the code on YOUR computer
```bash
git clone https://github.com/Graceface-07/torn-war-bridge.git
cd torn-war-bridge
```

### STEP 2: Start it
**Windows:**
```bash
start.bat
```

**Mac/Linux:**
```bash
./start.sh
```

**Or manually:**
```bash
npm install
node server.js
```

### STEP 3: Open your browser
```
http://localhost:3000
```

# ⚡ USE IT NOW - SUPER SIMPLE

## What You Need to Do:

### 1. Get Discord Bot Token (2 minutes)

Go to: https://discord.com/developers/applications

1. Click "New Application"
2. Name it anything (e.g., "Torn Bot")
3. Go to "Bot" tab on the left
4. Click "Reset Token" 
5. **COPY THE TOKEN** (you'll need it in next step)
6. Scroll down and enable:
   - ✅ MESSAGE CONTENT INTENT
   - ✅ SERVER MEMBERS INTENT
7. Click "Save Changes"

### 2. Run the Setup Script

**Windows:**
```
setup-bot.bat
```

**Mac/Linux:**
```
./setup-bot.sh
```

When it asks for your Discord token, **PASTE IT** and press Enter.

### 3. Invite Bot to Your Server

The script will show a link like:
```
https://discord.com/api/oauth2/authorize?client_id=123456789...
```

**Click it** and select your Discord server.

### 4. Use It!

In Discord, type:
```
/scan user_id:YOUR_TORN_ID faction_id:ENEMY_FACTION_ID
```

**DONE!** The bot scans and shows you results in Discord! 🎉
